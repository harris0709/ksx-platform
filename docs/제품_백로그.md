## PB-001 현업 SOP 문서 → MD 변환 기능

**배경:** S8 `documents` 컬렉션은 머리말(YAML)이 있는 MD 파일(`mapping/<기업>/sop/`)을 색인한다. IMPIX는 가상 SOP 11종(12개 판)을 직접 작성했지만, 실제 고객사는 문서관리시스템(DMS)의 Word·PDF·한글 문서를 가져와야 한다.

**범위(안)**

| 형식 | 방법(후보) | 주의 |
|---|---|---|
| Word(.docx) | Docling, MarkItDown, pandoc | 표·번호 목록 유지 확인 |
| PDF(텍스트) | Docling(표 구조 인식) | 머리글·바닥글·쪽번호 제거 |
| PDF(스캔) | 한국어 OCR → MD | 오인식 검토 필수 |
| 한글(.hwp/.hwpx) | HWPX(XML) 직접 변환, HWP는 변환 도구·HWPX 경유 | 국내 현업 다수, 도구 라이선스 확인 |
| Excel·PPT | MarkItDown 등 | 점검표·흐름도 손실 가능 |
| 그림·흐름도 | 그림 설명 추출 + 원본 링크 | 검토 필요 |

**흐름:** DMS·폴더 업로드 → 형식 변환 → 정리(머리글·쪽번호, 절 번호) → 머리말 자동 채움(DMS의 문서 번호·판·시행일·상태 + 관련 명사·연결 개체 후보 제안) → 현업 검토 화면(승인) → `mapping/<기업>/sop/` 저장 → `ksxkg sync` 색인(현행만 검색).

**원칙**
- 상태(현행·폐기)는 반드시 DMS 기준 — 폐기 판을 현행으로 올리는 것이 가장 큰 위험.
- `nouns`·`links`는 자동 제안 + 사람 확인. `links`가 지식 그래프에 없으면 동기화 실패(기존 검사)로 걸러진다.
- 변환은 자체 환경에서(외부 서비스 금지), 도구 라이선스는 구현안내서 15장(공급망 — 강한 카피레프트 격리) 기준으로 확인.
- 품질 시험: 변환 전후 표·수치·절 번호를 표본 대조하는 점검표.
