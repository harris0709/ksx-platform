# 기업 확장(Extension) 정의 양식

- `extensions/{ent}/확장정의서.xlsx`에 테이블 정의서와 같은 양식으로 작성합니다(구분 열 = 확장).
- 허용: 하위 클래스, 확장 속성, 확장 명사(ID 식별·기본 속성 3종·참조 대상 명시), 확장 코드, 현장 용어 별칭, 사내 제약.
- 금지: Core 정의의 수정·삭제·재정의, ksx: 이름 추가, Core 클래스에 대한 동치·배타 선언. 생성기가 발견하면 빌드가 실패합니다.
- 확장 속성의 물리 테이블은 ext 스키마의 1:1 확장 테이블(Core UK 참조)로 생성됩니다.
