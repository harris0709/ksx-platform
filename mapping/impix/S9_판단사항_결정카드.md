# S9 판단 사항 결정 카드 (IMPIX) — 사항 1건 = 1장

S9(MCP 도구·GraphRAG·LLM) 착수 전·진행 중에 **구현안내서와 다르게 하거나, 안내서가 정하지 않은 것**을 정한다.
한 장씩 순서대로 보여 주고 결정을 받은 뒤 다음 장으로 넘어간다. 결정은 `S9_승인기록.md`(작성 예정)의 "승인 요청 사항" 표에 옮겨 적는다.

## D-1. 개발·검증용 GPU 조달 — 어디서, 어떤 등급을, 어떻게 쓰고 정리하나

### ① 원천 (안내서·이전 단계가 정한 것)

- `S8_승인기록.md` 넘긴 과제: PC 벡터 색인(승인 조건, S9 착수 시), 재정렬 사용 여부(GPU·응답 시간 목표 결정 후, D-3), LLM·재정렬용 GPU 서버(개발 24GB, 검증 48GB 이상).
- `LLM서비스_아키텍처_하드웨어사양.docx`(인프라 전달본): 개발 GPU 24GB급, 검증 48GB급, 운영은 검증 측정 후 결정.
- PC 실측(S8): bge-m3 임베딩을 CPU로 돌리면 메모리 8.6GB/9.7GB를 써 PC가 느려짐 → max-batch-tokens 2048로 낮춤. CI(CPU)에서 재정렬은 질의당 약 50초, 임베딩 서버와 함께 띄우면 메모리 부족(OOMKilled).

### ② 결과와 근거

**GPU가 맡을 일 (나머지는 PC에 그대로)**

| GPU 서버 | PC(docker compose) |
|---|---|
| LLM 서빙(vLLM) · 임베딩 bge-m3(TEI) · 재정렬 bge-reranker-v2-m3(TEI) | 원장 DB·Fuseki·AGE·Qdrant·ksxkg·MCP 도구·CI 소스 |

- 연결: PC → SSH 터널 → GPU 서버 포트(공개 포트 없음). 임베딩 결과는 터널로 바로 PC Qdrant에 저장된다.
- 데이터: IMPIX는 가상 기업(실제 고객 데이터 없음). 실제 고객사 데이터를 쓰는 시점에는 국내 리전으로 옮긴다.

**종료 시 내려받을 것**

| 항목 | 위치 | 종료 시 |
|---|---|---|

**A안의 안전장치 (가입 직후 설정)**
1. SSH 키 접속만, 공개 포트 없음 — PC에서 SSH 터널로 접속.
2. 선불 충전 상한 + 잔액 알림, 월 예산 상한 20만 원(D-1 결정).
3. 유휴 자동 종료(GPU 사용 0이 30분이면 중지).
4. 모델은 네트워크 볼륨에 — 다시 켤 때 다시 받지 않음. 잔액 0이면 볼륨 없는 Pod 데이터는 사라지므로 중요한 것은 클라우드에만 두지 않는다.

**종료 점검표 (개발·검증 끝날 때)**
1. 결과가 PC·GitHub에 있는지 확인
2. (미세조정을 했다면) 결과물 내려받기
3. Pod·인스턴스 삭제
4. 볼륨·스냅샷 삭제(정지해도 저장 요금은 계속 나감)
5. API 키·SSH 키 회수
6. 다음 달 청구서 0 확인
