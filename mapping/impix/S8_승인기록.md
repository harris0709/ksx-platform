### 구현 중 정한 사항 (승인 시 함께 확인)

| 사항 | 정한 내용 | 근거 |
|---|---|---|
| 실행 방식 | `ksxkg sync` 배치(S7 D-1과 같은 원칙), 차이만 반영. Kafka 기반 pg-sync는 운영 단계 | S5·S7 도구·계획 파일과 같은 방식, 재실행 변경 0 확인 |
| AGE 서비스 계정 | 관리자 아닌 계정은 `LOAD 'age'`를 못 쓰므로, `age_schema.sql`(관리자 적용)이 `ksx_owner`·`ksx_reader`에 권한과 `session_preload_libraries='age'`를 건다. 쓰기는 라벨 테이블 직접(SQL) | 안내서 11.1의 "세션은 LOAD 'age'로 시작"은 관리자에게만 맞음 — v1.7에 반영 |
| 문서 원천 | IMPIX에 SOP가 없어 가상 SOP·규정 11건 작성(설비·공정·품질·납기 절차, 실제 기준정보·파라미터 규격과 일치, 폐기 판 1건 포함) | 현행 필터 확인에 폐기 판 필요 |
| 개체 색인 범위 | 자기 이름·설명이 있는 개체만(147) — 실적·LOT 등 식별값만 있는 개체는 속성 그래프·SPARQL로 찾음 | 번호만 있는 문장은 의미 검색 효과가 없음 |
| 이력 승인 여부 | 고객 클레임 종결(CLOSED), 시정조치는 결과가 있으면 approved=Y. 색인은 전부, 검색 필터는 S9에서 정함 | 안내서 표 28 "승인된 원인–조치 이력" |
