## 사후 변경 (S5 지식 그래프에서 회귀, 2026-11-04)

- `ksx:commonCodeGroup`(코드 정의 속성)을 객체 속성에서 문자 속성으로 고쳤다. Ontop이 T-Box와 매핑의 속성 종류 불일치로 기동을 거부해 발견했다. `ksxgen verify`에 "매핑 목적어 종류 = T-Box 속성 종류" 검사를 더했다(검증 10항목).
- Ontop용 Core + 확장 합본(`ontologies/ontop/ksx.obda`·`ksx.ttl`)과 물질화 매핑의 사업장 그래프 지정(`rr:graphMap`)을 생성물에 더했다. 트리플은 그대로다.
- 상세와 승인은 `S5_승인기록.md`의 S4R-01~03.
- (S6에서 회귀, 2026-11-09) 같은 이름 속성의 코드 IRI를 컬럼별 코드 그룹으로 만들도록 고쳤다(`ksx:errorCode`: 설비 → EquipmentErrorCode, 이송 → TransferErrorCode, 서비스 → ServiceErrorCode). 상세는 `S6_승인기록.md`의 S4R-04.
