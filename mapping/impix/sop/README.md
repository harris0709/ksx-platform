# IMPIX 작업표준·규정 문서 (S8 documents 컬렉션 원천)

가상 기업 IMPIX의 SOP·규정 문서입니다. 실제 기업에서는 문서관리시스템(DMS)의 현행·폐기 문서를 그대로 가져옵니다.
`ksxkg sync`가 이 폴더의 `*.md`(이 README 제외 — 머리말에 `doc_id`가 있는 파일만)를 500~800자 청크로 나눠 Qdrant `documents`에 색인합니다(구현안내서 11.2 표 28).

머리말(YAML):

| 항목 | 뜻 | 예 |
|---|---|---|
| doc_id | 문서 번호(판이 바뀌어도 같음) | SOP-DC-001 |
| version | 판 | 3 |
| status | 현행 / 폐기 / 초안 — 검색은 **현행만**이 기본(폐기·초안을 현행으로 오인 방지) | 현행 |
| title | 제목 | 다이캐스팅 작업표준 |
| effective | 시행일 | 2026-07-01 |
| owner | 주관 부서 | D110 |
| nouns | 관련 명사(표준) | [Equipment, TraceParameter] |
| links | 연결 개체 `라벨:식별값` → 지식 그래프 IRI로 바꿔 payload `iris`에 둔다(못 찾으면 동기화 실패) | Equipment:DCM-02 |
