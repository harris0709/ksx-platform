# 누설시험 표준

## 1. 적용 범위

조립한 전동식 워터펌프 전수를 누설시험기 LKT-01·LKT-02로 시험하는 누설시험 공정(A200)에 적용한다.

## 2. 시험 조건과 판정

시험압력은 190~210 kPa(관리 194~206 kPa)로 하고, 누설량 2.0 cc/min 이하를 합격으로 한다. 누설량 1.5 cc/min을 넘으면 경고로 기록한다. 시험압력이 규격을 벗어난 시험은 무효로 하고 다시 시험한다.

## 3. 불합격 처리

불합격품은 1회에 한해 재시험한다. 재시험도 불합격이면 누설 불량으로 확정하고 생산실적 품질에 불량수량을 기록한다. 같은 조립 LOT의 누설 불량률이 5%를 넘으면 해당 LOT 전체를 보류(H)하고 품질보증파트에 통보한다.

## 4. 원인 조사

누설 불량이 몰리면 투입 하우징 LOT을 역추적해 주조 시점의 금형온도 스펙아웃과 기공 불량 이력을 확인한다. 하우징 기공이 원인이면 해당 주조 LOT으로 만든 다른 조립 LOT도 함께 보류한다.
