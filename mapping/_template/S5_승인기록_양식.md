## 완료 기준 확인

| 기준(표 19) | 근거(`S5_검증결과.md`, CI `s3-load`) | 결과 |
|---|---|---|
| 가상 질의 결과 = SQL 결과 | Ontop 클래스 <n>개 개체 수 = 원장 행 수(차이 <n>), 사업장별 로트 수 SPARQL = SQL | <충족 / 미충족> |
| 물질화 트리플 수 = 기대치 | (그래프, 클래스) <n>쌍 개체 <n> = 매핑 SQL 행 수(물질화 필터 적용), 그래프 <n>개 트리플 <n> = 물질화 기록 | |
| 사업장별 그래프 분리 확인 | 공장 그래프 사업장 불일치 <n>, 공통 그래프의 비기준정보 <n>, 공장 그래프의 기준정보 <n>, 두 그래프 개체 <n>, 기본 그래프 <n>, 데이터 그래프 = 원장 공장 <n> + 기업 공통 | |

PC와 CI가 같은 숫자를 내야 한다(같은 원장·같은 설정). 다르면 PC의 코드가 최신인지(`git log`) 먼저 본다.
