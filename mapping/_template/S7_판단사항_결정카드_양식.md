# S7 판단 사항 결정 카드 — 양식 (사항 1건 = 1장)

S7 규칙 추론 중 **구현안내서와 다르게 하거나, 안내서가 정하지 않은 것**, 그리고 **규칙 결과의 의미·구조**를 정하는 자료다(IMPIX D-1~D-5).
승인 회의에서 **한 장씩 순서대로** 보여 주고, 결정을 받은 뒤 다음 장으로 넘어간다.
결정은 `S7_승인기록.md`의 "승인 요청 사항" 표 결정 열에 옮겨 적고, 안내서를 고쳐야 하면 "구현안내서 반영" 표에도 적는다.
결정으로 규칙·사례·어휘가 바뀌면 반영 → `infer` 다시 실행 → 바뀐 숫자로 다음 카드를 보여 준다.
**결정 내용은 평가 사례로도 남긴다**(예: 납기 상태 → 사례 E13) — CI가 결정이 지켜지는지 계속 확인한다.

S7에서 판단 사항이 되는 것과 근거를 모으는 방법:

| 유형 | 예(IMPIX) | 근거를 모으는 방법 |
|---|---|---|
| 실행 도구·주기 | D-1 배치(ksxkg infer) vs Airflow·Kafka | 규칙 실행 시간(초), 운영 스케줄러 준비 상태, 이벤트성 규칙 유무 |
| 정답(수작업 판정) 방법 | D-2 업무 질의 사례 + 원천 전수 | 규칙별 결과 수 대비 사례 수, 두 경로(질의 답·원천 조회) 일치 여부 |
| 기준일·시간 의미 | D-3 지난 납기 포함 | 결과의 날짜 분포(기준일 대비), 업무 질의 문구, 데이터 기간 |
| 이벤트 구조 | D-4 원인이 여럿인 이벤트 | 이벤트당 원인 수, 값과 원인의 짝, 리스크 건수 세는 방법 |
| 어휘·의미 | D-5 inf: 어휘 선언 | 규칙이 쓰는 inf: 어휘 수, 레이블·정의 유무, S8·S9에서 읽는 방식 |
| 원천 구조 | (예) 계보가 모로트 참조가 아니라 투입품목에 있음 | 원천 조회로 길별 건수(0건 vs 77건) — 규칙 경로 선택 |
| 임계값 | (예) 불량률 2%, 납기 7일 | 결과 건수 변화(임계값별), 업무 질의·KPI 기준 |
