# S4 판단 사항 결정 카드 — 양식 (사항 1건 = 1장)

S4 생성·검증 중 **구현안내서와 다르게 하거나, 안내서가 정하지 않은 것**을 정하는 자료다(IMPIX D-1~D-5).
승인 회의에서 **한 장씩 순서대로** 보여 주고, 결정을 받은 뒤 다음 장으로 넘어간다.
결정은 `S4_승인기록.md`의 "승인 요청 사항" 표 결정 열에 옮겨 적는다. 안내서를 고쳐야 하면 "구현안내서 반영" 표에도 적는다.

판단 사항이 되는 것:

| 유형 | 예(IMPIX) |
|---|---|
| 안내서와 다른 도구·명령 | D-1 일관성 검사 Openllet → ROBOT(HermiT) |
| 검증에서 찾은 표현 문제와 고치는 위치 | D-2 기간 interval → ISO 8601(매핑 SQL에서) |
| 생성물끼리 겹치거나 부딪힘 | D-3 자동 전이 규칙 A-004와 업무 규칙 R-001 |
| 다음 단계가 그대로 쓸 이름·구성 | D-4 속성 그래프 이름 `ksx_graph`, 코드는 노드 속성 |
| 이번 단계의 범위 | D-5 도구 스키마는 어휘로 정해지는 2개 서버만 |
