## 작성 요령

| 항목 | 요령 |
|---|---|
| 원천 데이터 | 원천 컬럼 이름 그대로 쓴다. 표준 이름으로 바꾸지 않는다(현업이 자기 화면과 대조) |
| 교차 확인 | 한 행만 보지 말고 **전체 분포**와 비교한다 |
| 분석 | 사실과 추정을 나눠 쓴다 |
| 선택지 | 현재 방식과 권장안을 표시한다. 보정·대체는 원천 안의 근거가 2개 이상일 때만 권장한다 |
| 같은 원인 | 여러 테이블에 퍼진 같은 원인(예: 생산실적·완공·생산실적 설비)은 한 장에서 함께 결정한다 |
| S2 회귀 | 매핑 명세를 바꿔야 하는 결정도 같은 카드로 검토하고 `s2_regressions`에 적는다 |
