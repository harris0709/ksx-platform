# S5 판단 사항 결정 카드 — 양식 (사항 1건 = 1장)

S5 구성·검사 중 **구현안내서와 다르게 하거나, 안내서가 정하지 않은 것**을 정하는 자료다(IMPIX D-1~D-5).
승인 회의에서 **한 장씩 순서대로** 보여 주고, 결정을 받은 뒤 다음 장으로 넘어간다.
결정은 `S5_승인기록.md`의 "승인 요청 사항" 표 결정 열에 옮겨 적고, 안내서를 고쳐야 하면 "구현안내서 반영" 표에도 적는다.
결정으로 설정·생성물이 바뀌면 materialize → check를 다시 돌려 숫자를 갱신한 뒤 다음 카드로 간다.

S5에서 판단 사항이 되는 것과 근거를 모으는 방법:

| 유형 | 예(IMPIX) | 근거를 모으는 방법 |
|---|---|---|
| IRI 규칙 | D-1 IRI에 사업장·공장 경로를 넣을지 | 원장 FK마다 자식·부모 행의 PlantID가 다른 건수(다른 공장 참조) |
| 그래프 배정 | D-2 기준정보를 기업 공통 그래프에 둘지 | 기준정보 명사별 공장 분포, 다른 공장에서 참조하는 건수 |
| 물질화 범위 | D-3 고빈도 시계열·오래된 거래를 물질화할지 | 매핑별·그래프별 트리플 수(비중), 시계열의 이벤트 행 수, 거래 일자 범위 |
| 적재 방식 | D-4 다시 실행할 때 PUT 교체 vs 차이 반영 | 그래프 크기별 반영 시간(materialize 출력의 초) |
| 격리·권한 | D-5 가상 그래프(Ontop)의 사업장 격리 | 원장 RLS 적용 테이블 수, 엔드포인트 노출 범위(포트 바인딩) |
