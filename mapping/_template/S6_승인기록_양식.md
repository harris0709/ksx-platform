## 완료 기준 확인

| 기준(표 23) | 근거 | 결과 |
|---|---|---|
| 의도적으로 넣은 위반 10건 전건 검출 | `S6_의도적위반시험.md`: 4차원(구조 <n>·값 <n>·관계 <n>·의미 <n>) <n>/10 검출, 정상 대조군 결과 <없음/있음> | <충족 / 미충족> |
| 리포트 자동 생성 | `ksxkg validate` → `S6_검증결과.md`(그래프×차원, 셰이프별, 대상 예, 매개변수) + `audit.shacl_result` | |
| 위반 데이터의 추론 제외 확인 | 시험: 위반 seed <n>건 <규칙>에서 제외, 대조군 포함. 실데이터: <규칙> 결과 <n>개 중 위반 개체 <n>(0이어야 함) | |

PC와 CI가 같은 숫자를 내야 한다(같은 원장·같은 설정). 다르면 PC 코드가 최신인지, 물질화가 최신인지 먼저 본다.
