# S8 판단 사항 결정 카드 — 양식 (사항 1건 = 1장)

S8 속성 그래프·벡터 인덱스 중 **구현안내서와 다르게 하거나, 안내서가 정하지 않은 것**, 그리고 **완료 기준을 못 맞출 때 무엇을 고칠지**를 정하는 자료다(IMPIX D-1~D-3).
승인 회의(또는 진행 중 결정이 필요한 시점)에서 **한 장씩 순서대로** 보여 주고, 결정을 받은 뒤 다음 장으로 넘어간다.
결정은 `S8_승인기록.md`의 "승인 요청 사항" 표 결정 열에 옮겨 적고, 안내서를 고쳐야 하면 "구현안내서 반영" 표에도 적는다.
결정으로 계획·카드 문장·평가 세트가 바뀌면 반영 → `sync` 다시 실행 → 바뀐 숫자로 다음 카드를 보여 준다.
**평가 질문을 색인 문장에 넣어 점수를 올리지 않는다** — 그러면 recall이 의미를 잃는다.

S8에서 판단 사항이 되는 것과 근거를 모으는 방법:

| 유형 | 예(IMPIX) | 근거를 모으는 방법 |
|---|---|---|
| 검색 지표·역할 | D-1 명사 카드는 출발점 명사 적중@5, 전부 찾기는 S9 | 질의당 정답 수 분포, recall과 적중의 차이, 놓친 사례의 성격(여러 명사 vs 말이 없음) |
| 카드 문장 | D-1 업무 용어, D-2 짧은 카드(속성 목록 생략) | 놓친 사례의 질문 단어가 카드에 있는지, 여러 카드에 두루 붙는 말, 단계별 적중 변화 |
| 평가 정답 | D-2 S2 확장 명사를 정답에 더함 | 검색 1위가 확장 명사인 오답 수, S1 KPI정의서 '원천 공백·Extension' 기록 |
| 모델·자원 | D-3 재정렬은 S8에서 끔 | 질의당 처리 시간(CPU/GPU), 메모리(`docker stats`), 재정렬 없이 기준 충족 여부 |
| 실행 방식 | 배치(ksxkg sync) vs Kafka | 재실행 변경 0, 반영 시간, 운영 스케줄러 준비 상태 |
| AGE 계정·권한 | 관리자 아닌 계정의 AGE 사용 | `LOAD 'age'` 권한 오류, `session_preload_libraries` 적용 여부 |
| 색인 범위 | nodes = 이름 있는 개체, cases 승인 표시 | 명사별 개체 수, 식별값만 있는 개체의 검색 효과 |
| 문서 원천 | 가상 SOP 작성 / DMS 연계 | 현행·폐기 판 유무, links 해소율 |
