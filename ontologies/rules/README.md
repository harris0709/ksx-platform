# 추론 규칙 (저작물 — 생성기 대상 아님)

`ontologies/` 안에서 이 폴더만 사람이 작성합니다. 파일명 순서대로 실행되며, 앞 규칙의 결과를 뒤 규칙이 쓸 수 있습니다.

| 파일 | 유형 | 내용 |
|---|---|---|
| R-001_lot_genealogy.rq | 전이 | 로트 계보 전개(모로트 전체) |
| R-002_bom_direct.rq | 체인 | 자재명세서 직접 구성품(헤더 → 라인 → 자품목) |
| R-003_bom_explosion.rq | 전이 | 다단 BOM 전개(R-002 결과 사용) |
| R-010_affected_sales_order.rq | 체인 | 생산실적 → 생산지시 → 수주라인 → 수주 |
| R-100_otd_risk.rq | 업무 규칙 | 불량률·납기 기준 납기 리스크 이벤트 |

파라미터(`${name}`)는 `params.yaml`에서 채웁니다. 규칙에서는 `ksxq:violates` 표식이 있는 개체를 제외합니다(S6).
